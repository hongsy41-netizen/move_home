## 기능

- 항목 추가 / 수정 / 삭제, 체크박스 완료 토글 (메모·금액·일정 포함)
- **완료 vs 예약완료**: 실제 시공·설치가 끝난 항목만 `완료` 체크, 예약만 된 항목은 `📌 예약완료` 뱃지로 표시(시공 후 체크). 모달에서 예약완료 토글 가능
- **내 항목 vs 💡 추천 제안**: 성윤 님이 직접 말한 항목·직접 추가한 항목은 `내 항목`, Pickle이 미리 넣어 둔 후보는 `💡 추천 제안` 뱃지. 필터 칩으로 `전체 / 🙋 내 항목 / 💡 추천 제안` 전환, 제안은 `🙋 내 항목으로`로 옮기거나 삭제
- **상단 요약 두 블록**: 🏠 아파트 계약·입주 자금(12/17 — 들어올 돈 11억 / 나갈 돈 약 9억 9,383만 / 예상 여유 약 9,900만, 「자금 계획 상세」로 이동)과 🛋️ 이사·시공·생활 비용(18,555,600원)을 완전히 분리해 표시
- **💰 비용·결제 내역 뷰**: 금액이 있는 항목만 모아 항목·업체·낸 돈·앞으로 낼 돈·총액·상태를 표로 비교·합산(모바일은 카드형)
- **🏦 12/17 입주 자금 항목별 출처**: 나갈 돈 8건·들어올 돈 2건마다 근거(📄 안내서·정산표 문서명과 항목 번호, 📱 대출 앱, 💬 직접 입력)를 함께 표시. 서류 원본은 올리지 않고 서류명·항목 번호만 적음
- **📅 날짜별 일정 뷰**: 일정(날짜)이 잡힌 항목을 날짜순 타임라인으로 모아 보기. 위에 12/14 줄눈 → 12/15 비움 → 12/16 입주청소 → 12/17 이사 → 12/18 인터넷·무타공 TV 핵심 5일 카드, 아래에 날짜별 카드(항목 많으면 오전/오후·시간순 정렬, 12/15는 "일정 없음 — 비워 둔 날" 카드), 맨 아래에 **날짜 미정 항목 개수(접힌 목록)**. 타임라인에서 바로 체크·수정 가능
- **업체명 + 낸 돈(계약금) / 앞으로 낼 돈(잔금)**: 항목마다 업체와 금액을 나눠 적고, 상단 요약에서 **총 금액 · 낸 돈 합계 · 앞으로 낼 돈 합계**를 실시간 집계
- 이전 버전의 단일 `금액` 저장값은 자동 호환(완료 항목은 낸 돈, 미완료 항목은 앞으로 낼 돈으로 이동)
- 브라우저 `localStorage` 자동 저장 (데이터 버전 17 — v9 저장값은 확정 5건(12/14 줄눈 · 12/16 입주청소 · 12/17 가구·이삿짐 최종 확인·엘리베이터 재확인) 외의 임의 날짜를 비우고 예약완료·추천 제안 플래그, 입주청소 선입금, 조명·살 것들·안방 TV 거치대까지 보정하며, v10에서 12/17 자금 항목·일정·메모를 중복 없이 반영, v11에서 12/18 확정 일정(오전 인터넷 이전설치 · 오후 거실 무타공 TV)만 두 항목에 반영, v12에서 기업은행 주담대 준비서류 5건을 주담대 항목 뒤에 중복 없이 추가하고 주담대 메모에 기업은행 금리 조건을 보강, v13에서 소득서류 메모의 홈택스 문구를 사진 원문대로 정정("홈택스 발급분은 불가"), v14에서 인터넷 이전설치 항목을 `📌 예약완료` · 12/18(금) 설치 확정으로 표기, v15에서 인터넷 이전설치 시간을 오전 10시로 확정해 항목 메모·12/18 카드·일자 안내문에 함께 표기, v16에서 통신사를 LG U+로 밝히고 이사할 때 챙길 단말 6개(셋탑박스 UHD3 ×2 · WiFi폰 Dock OTT 리모컨 ×2 · 유선홈GW HGWD-1G ×1 · 기가 Wi-Fi GAPM-7100 ×1)를 인터넷 이전설치 메모·12/17·12/18 안내문에 넣고 이사 당일 항목을 추가, v17에서 서류 5장(법률사무소 가온 등기·취득세 안내, 분양금 납부 안내 26.12.01 기준, 제우스디자인·쾌존·린다데코 계약서)을 반영해 등기·취득세 항목을 내 항목으로 올리고 서류 6종 항목을 추가, 취득세·등기·법무비용을 84A 기준 2,200만 원으로 정정, 줄눈·쾌존·가구 메모에 시공 범위·품목·A/S·문의처(끝 4자리)를 보강)
