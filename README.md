## 기능

- 항목 추가 / 수정 / 삭제, 체크박스 완료 토글 (메모·금액·일정 포함)
- **완료 vs 예약완료**: 실제 시공·설치가 끝난 항목만 `완료` 체크, 예약만 된 항목은 `📌 예약완료` 뱃지로 표시(시공 후 체크). 모달에서 예약완료 토글 가능
- **내 항목 vs 💡 추천 제안**: 성윤 님이 직접 말한 항목·직접 추가한 항목은 `내 항목`, Pickle이 미리 넣어 둔 후보는 `💡 추천 제안` 뱃지. 필터 칩으로 `전체 / 🙋 내 항목 / 💡 추천 제안` 전환, 제안은 `🙋 내 항목으로`로 옮기거나 삭제
- **💰 비용·결제 내역 뷰**: 금액이 있는 항목만 모아 항목·업체·낸 돈·앞으로 낼 돈·총액·상태를 표로 비교·합산(모바일은 카드형)
- **업체명 + 낸 돈(계약금) / 앞으로 낼 돈(잔금)**: 항목마다 업체와 금액을 나눠 적고, 상단 요약에서 **총 금액 · 낸 돈 합계 · 앞으로 낼 돈 합계**를 실시간 집계
- 이전 버전의 단일 `금액` 저장값은 자동 호환(완료 항목은 낸 돈, 미완료 항목은 앞으로 낼 돈으로 이동)
- 브라우저 `localStorage` 자동 저장 (데이터 버전 7 — 기존 저장값은 예약완료·추천 제안 플래그까지 자동 보정)
- JSON 백업 내보내기 / 불러오기, 기본값 초기화
- 카테고리 필터, 미완료만 보기, 검색(항목·업체·메모), 낸 돈 비중 바
- 모바일/데스크톱 반응형 라이트 테마
